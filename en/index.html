A few useful answers

Before we start.

Start a project
I only have an idea. Can we start there?

Yes. Tell us who you want to reach and what you want to make easier. You do not need a technical specification to start a conversation.

How much will my project cost?

The scope comes first: pages, features, content and integrations. Share what you need so we can discuss a quote for your project.

Can you improve an existing website?

Share its link and explain what you want to change. We can review the current setup and discuss suitable improvements.

Can my website use more than one language?

Yes. We can plan Arabic, French and English versions, including a right-to-left Arabic layout. The languages and content are agreed for each project.

How can I explore the clinic system?

Choose “Clinic system” in the contact form to request a demonstration. The preview above is illustrative; the application is described in French and English.
