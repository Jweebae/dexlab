# DexLab website

Source of https://dexlab.store, served by GitHub Pages from the `main` branch root.

- Text in Arabic, French and English: `content/strings.json`
- Generate the pages after editing text: `python3 tools/build.py`
- Styles: `assets/css/site.css` · Behaviour: `assets/js/site.js`
- `CNAME` must stay (custom domain).

Brand rules and the full project log live in the DexLab project folder (`DexLab/README.md`, `DexLab/brand/`).
